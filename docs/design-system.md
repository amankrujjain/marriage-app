# Design system — Shaadi Invitation

Product UI should feel like a simple Indian wedding / invitation site, not a SaaS landing.

## Tokens

| Token | Role |
|-------|------|
| `--color-maroon` | Primary actions, emphasis |
| `--color-gold` | Accents, hairlines |
| `--color-ivory` | Page ground |
| `--color-blush` | Soft wash end |
| `--color-ink` | Body text |

## Typography

- **Display / brand:** Fraunces
- **Body / UI:** Figtree

Never use Inter, Roboto, Arial, or system-ui as the primary stack.

## Composition rules

- Brand name is the hero-level signal on the first viewport
- One headline line, one CTA group — no cards in the hero
- Subtle paisley/mandala atmosphere at low opacity
- Mobile-first, large touch targets

## Anti-patterns

- Purple / indigo SaaS gradients
- Cream + terracotta “AI brochure” look
- Glow shadows, pill clusters, glassmorphism
- Dashboard chrome, emoji, floating promo badges

Biodata **templates** may be richer; the app chrome stays invitation-clean.
